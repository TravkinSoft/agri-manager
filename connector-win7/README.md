# Travkin Connector · Windows 7 · проверка RS-232

Версия 1.1.0 — этап диагностики, **не автоматическое взвешивание**.
Требуется Windows 7 SP1 (32 или 64 бита) с .NET Framework 4.8 либо более новая Windows.
Windows 7 больше не поддерживается Microsoft. Не переустанавливайте рабочую ОС во время смены.

## Для весовщика

1. На компьютере весовой скачайте установщик из «Весовая → ⋯ → Подключение весов».
2. Установите MSI и откройте «Travkin Connector · проверка весов» из меню «Пуск → TravkinFlow».
3. Если отсутствует .NET Framework 4.8, установщик остановится с понятным сообщением. Нужен именно 4.8, не 4.8.1 и не .NET 8. Официальная загрузка: https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48
4. Подключение RS-232 должно соответствовать штатному кабелю Метра. Если на ПК только USB, необходим подходящий USB–RS232 переходник с драйвером для Windows 7. Программа не ставит неизвестные драйверы, не перебирает порты и не меняет параметры прибора.
5. Выберите COM-порт и параметры связи, сверенные с прибором или штатной программой. Если порт занят, не закрывайте рабочую программу без согласования. Не подключайтесь одновременно к занятому COM-порту.
6. Нажмите «Подключить». Появление байтов подтверждает приём данных, но ещё не правильность веса. Подключение без байтов этого не подтверждает.
7. Запишите пустую платформу и штатное взвешивание, отмечая реальное показание, единицы, режим брутто/нетто и индикатор стабильности. «Сохранить диагностику» создаёт текстовый файл для настройки парсера. Не выполняйте специальную тарировку или калибровку для этой проверки.

Программа только читает выбранный порт. Не отправляет команды нуля, тары, калибровки или настройки. Не открывает сеть, не получает пароли TF, не меняет талоны/остатки. Запись ограничена последними 200 блоками по 1024 байта; сохраняйте нужный отрезок своевременно. В файле HEX — точные байты, ASCII — их удобное представление. Непечатаемые байты показаны как `\xHH`.

Установщик пока без цифровой подписи издателя. Не отключайте антивирус, SmartScreen или проверку драйверов. Проверяйте имя и SHA-256 файла; при блокировке обратитесь к администратору.

## Что подтверждено / что нет

- Фото: Микросим-06, М0601-БМ-2.1, НПП «Метра», №38854, 2016 г.; X3/X4 имеют маркировку RS232. Кабель RS-232 подтверждён владельцем.
- Не подтверждены: распайка конкретного кабеля, номер COM, скорость/кадр, режим выдачи прибора, реальный протокол, единицы, Windows 7 SP1 и драйвер на рабочем ПК.
- Старый .NET 8 Connector остаётся неизменным в отдельной рабочей папке. Его бинарник сюда не включён.
- Сборка и автоматические проверки выполняются на Windows 11 с .NET Framework. Запуск/установка на реальном Windows 7 и приём сигнала Метра — отдельный обязательный выездной тест.
- Автоподстановка в TF не реализована в этой диагностической версии. Следующий этап: по захвату подтвердить формат, стабильность, единицы и брутто/нетто, добавить защищённую передачу показаний на сайт и провести сквозной тест без изменения боевых талонов.

## Воспроизводимая сборка

`build.ps1` компилирует C# средствами .NET Framework, запускает проверки без COM, собирает MSI с WiX 6.0.2. Скрипт не устанавливает и не запускает приложение и не пишет автозапуск/реестр. Артефакты кладутся в `artifacts`.

Изготовитель: https://www.metra.ru/catalog/pribory/mikrosim-0601-bm-vesoizmeritelnyj-pribor/

Совместимость .NET Framework: https://learn.microsoft.com/en-us/dotnet/framework/get-started/system-requirements
