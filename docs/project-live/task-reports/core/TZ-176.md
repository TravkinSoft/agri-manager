## Blocking security drift

Acceptance stopped on the required global-reference mutation denial.
`global_product_aliases` on `assistant-memory-a106` has RLS disabled and the
`authenticated` role has UPDATE privilege. A real QA User A JWT successfully
returned the fixture alias from an UPDATE whose value was unchanged. Production
already has RLS enabled with authenticated-read and global-admin-only mutation
policies, but that later production security hardening is absent from this
older divergent Assistant branch.

TZ-176 authorization covers branch-only reference and business writes, not a
schema/RLS migration. No branch policy, migration history, production schema or
business data was changed to hide the failure. A107 must not start until a
separate owner-approved task aligns the branch alias security with the already
canonical production definition and repeats this real-JWT test.
