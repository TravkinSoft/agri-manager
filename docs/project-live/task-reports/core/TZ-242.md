## Architecture

  one warehouse request with multiple items, warehouse issue allocations,
  stock ledger, Specialist progress, field history, weighbridge tickets and
  inventory batches.
- Added `crop_mix` only as a land-use type. No crop, global product, variety or
  separate mixture catalog named `Зерносмесь` was created.
- Added `crop_structure_mix_components` for the ordered crop, variety,
  reproduction and kg/ha identities. The root keeps the area once and has no

  component identity has been fully issued.
- Harvest creates one company-local derived inventory identity, one mixed batch,
  one ledger IN and one field-history trace with an immutable composition
