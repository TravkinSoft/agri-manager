# TZ-239 - Remove Package Complexity from Warehouse Issue

STATUS: `PASS`

## Result

Warehouse preparation and issue now use one direct material quantity. The
warehousekeeper no longer selects package size, package count, whole-package
mode, measured mode or a manual package reason.

The request contains exactly six business columns: material, planned
requirement, available, to issue, expected return and status. The agronomist
plan stays immutable. Issue above plan is allowed when stock is sufficient;
issue above available stock is rejected. Expected return is
`max(issue quantity - planned quantity, 0)`.

Ordinary receipts do not require package metadata. Existing package columns and
historic values were preserved but are ignored by the active Warehousekeeper
and Specialist contracts. Internal lot allocation remains deterministic and is
not exposed as package work.
