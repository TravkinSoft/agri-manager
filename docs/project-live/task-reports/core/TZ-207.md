## Weighbridge contract

Harvest tickets require a linked harvest operation and operation line belonging to
the same company and field. Ticket creation has a request fingerprint and
idempotency key; a same-payload retry reuses the ticket and a conflicting retry is
rejected. Finalization is idempotent and uses an authenticated session wrapper
that derives the actor from `auth.uid()`, validates role/company access and calls
the existing atomic weighbridge finalizer. The wrapper is applied only to the test
branch for preview acceptance.
