## Inventory and model decision

The production catalog was inventoried read-only and contains exactly `852` global pesticide cards, `627` aliases, `1385` product-component links and `367` referenced components. Existing detailed usage-rule rows were `0`. No company product or business row was read, and production writes were `0`.

Full Pesticide Card V1 extends the existing product model. It reuses `products`, manufacturers, formulations, aliases, GLBD components and component sources/links, plus canonical crops, varieties, diseases, pests and weeds. It adds four branch-only detail tables:

- `glbd_product_sources` for claim-scoped evidence;
- `glbd_product_registrations` for registration history;
- `glbd_product_usage_rules` for canonical crop/target application rules;
- `glbd_product_assistant_safety` for explicit read and recommendation gates.

All four tables have RLS, authenticated SELECT-only policies and explicit grants. Runtime reads use the user's JWT; no service-role key is used by the application route. Security Advisor found no new finding for these tables. FK indexes were added after the first performance review; remaining unused-index notices are expected for newly created pilot tables.
