## Result

TravkinFlow now has one canonical global counterparty catalog keyed by country plus tax ID. The approved source imported exactly 108 legal identities: 89 Kazakhstan and 19 Russia. Tax IDs remain strings, source validation found no invalid or duplicate identities, and a repeated import changed zero rows.

The existing company `counterparties` table remains the company-level link and local-record surface. Company Admin can link a global identity or create a guarded local record; warehouse roles can only search and select. New supplier receipts no longer accept free text. The receipt RPC creates or restores the company link in the same transaction as header, lines, finalization and ledger `IN`.
