## Result

Warehousekeeper V1 now has a role-scoped workspace for agrochemical warehouses. The sidebar contains exactly Dashboard, Warehouses, Stock movements, Issue requests and All stocks. Warehouse creation and lifecycle management remain company-admin actions; weighbridge keeps read/select access needed by the existing harvest-ticket flow.

The warehouse page uses compact warehouse cards and a central warehouse dialog. A warehousekeeper can post a supplier receipt for pesticides, fertilizers and additives without an agronomist operation. The receipt RPC creates the receipt header, lines and ledger `IN` rows atomically and treats the same request fingerprint as an idempotent replay. Seeds and harvest intake are rejected.

The issue board has three active columns, moves history into a separate dialog and keeps issuing tied to an operation material request. Existing TZ-204 issue, return, loss, reconciliation and field-history contracts were not changed.
