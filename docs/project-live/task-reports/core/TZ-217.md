Date: 2026-07-23

Branch: `copilot-v1`

Status: `DONE`

## Result

Warehousekeeper, Weighbridge Operator and Agronomist now receive the same company-scoped list of all active warehouses. Company Admin receives the same active list plus archived warehouses in a separate section. The top level is loaded from warehouses, so an empty warehouse remains visible.

The shared `/warehouses` page uses one hierarchy:

`warehouse -> aggregated stock and batches -> full harvest batch`

Role differences are limited to actions. Warehousekeeper actions appear only for agrochemical warehouses. Grain, harvest and seed warehouses are read-only. Weighbridge Operator and Agronomist are read-only on the warehouse page. Company Admin can open warehouse management but cannot post stock movements.
