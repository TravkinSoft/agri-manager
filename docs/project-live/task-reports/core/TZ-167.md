No table was made company-scoped and no artificial `company_id` was added. Anonymous access is denied. RLS was enabled only on the temporary branch; each table received command-specific read/insert/update/delete policies with no permissive write expression.

## Function hardening

All 27 public `SECURITY DEFINER` functions received deterministic `search_path = pg_catalog, public`. Default `PUBLIC`, anonymous and broad authenticated execution was revoked.

- 22 privileged business/import RPCs: `service_role` only;
- 2 trigger functions: no direct execute grant;
- 4 read/session helpers plus guarded treatment sync: authenticated and service role;
- three import RPCs with arbitrary `_actor` input: no direct authenticated execution;
- `sync_treatment_program_links`: original implementation moved to `private`; public wrapper enforces active role and own-company access, while preserving global-admin and service-role behavior.
