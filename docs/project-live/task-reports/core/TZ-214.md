## Result

The weighman workspace now contains exactly Weighbridge, Warehouses and Ledger. The Warehouses page is read-only and groups harvest batches by warehouse with received mass, removed impurities, clean mass, impurity percentage and gross/clean yield.

The current Processing tab, processing destination, queues and dedicated page are removed. Historic records and schema remain intact. Harvest intake always selects a warehouse and preserves the TZ-213 hidden harvest-operation and operation-line links.

`Вывоз примесей` is a normal outbound weighbridge ticket linked to an existing harvest batch. Its form order is warehouse, batch, impurity type, driver, vehicle, gross, optional comment and create. Closing captures tare, calculates net and atomically creates a `WEIGHBRIDGE_IMPURITIES` ledger OUT. `Прочее` requires a comment.
