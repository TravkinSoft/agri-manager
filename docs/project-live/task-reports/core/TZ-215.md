## Result

Company Admin now owns company reference entities and warehouse definitions, while Warehousekeeper owns physical stock operations. The server/API layer enforces the same split. Company references use the selected company and active season through user JWT/RLS reads; no service role is required by Preview.

## Warehouse permissions

- Company Admin can list, create, update, archive and restore company warehouses from `/warehouses/manage`.
- Company Admin sees warehouse balances read-only and does not see receipt or inventory actions.
- Warehousekeeper sees receipt and inventory actions and is redirected away from `/warehouses/manage`.
- Warehouse receipt writes allow only `global_admin`, `warehouse` and `warehouse_operator`.
- Warehouse entity writes allow only `global_admin` and `company_admin`.
